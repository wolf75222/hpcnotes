🔗 Intégration Google Sheets

Configurez une URL de webhook pour envoyer automatiquement chaque profil ajouté vers une Google Sheet.

Laissez vide si vous n'utilisez que l'export Excel local.

📖 Comment créer un webhook Google Sheets

  1. Ouvrez une Google Sheet où vous voulez recevoir les données
  2. Allez dans Extensions → Apps Script
  3. Copiez-collez le code fourni dans le README
  4. Cliquez sur Déployer → Nouveau déploiement
  5. Choisissez Application web
  6. Dans "Qui a accès", sélectionnez "Tout le monde"
  7. Cliquez sur Déployer
  8. Copiez l'URL fournie et collez-la ci-dessus

🗂️ Données stockées

Vos données sont stockées localement dans votre navigateur. Elles ne sont jamais envoyées ailleurs que vers le webhook optionnel que vous configurez.
